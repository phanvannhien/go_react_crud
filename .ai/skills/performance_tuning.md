# Skill: Performance Tuning

Backend:
- Detect N+1 queries
- Suggest indexes
- Add pagination if missing
- Detect unnecessary SELECT *
- Recommend context timeouts

SQL:
- Add LIMIT
- Suggest composite index
- Remove redundant joins

Go:
- Avoid unnecessary allocations
- Use sync.Pool when needed
- Profile before optimizing

Frontend:
- Avoid unnecessary re-renders
- Use memoization
- Lazy load routes
- Code splitting with Vite

Output:
- Bottleneck analysis
- Suggested changes
- Estimated impact
